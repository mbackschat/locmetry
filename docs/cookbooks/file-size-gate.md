# File-Size Gate Cookbook

The file-size recipes moved into the [reports guide](../guides/reports.md#gate-file-sizes) on 2026-10-31, so that the executable serves them: `locmetry --guide reports --section gate-file-sizes`. They limit source files by purpose, warn at soft limits and freeze the size of existing large files. [LOCmetry's own gate](../self-measurement.md#file-sizes) records its limits and ceiling policy.
