# locmetry 0.3.0

This minor release adds adaptive detail to the terminal Folder table and fixes control-character handling in terminal output. Measurement and classification semantics are unchanged from 0.2.0.

## Adaptive Folder detail

Use `locmetry path/to/project --folder-rows 30` to expand the existing Folder table into deeper, non-overlapping rows without rescanning or changing project scope. This changes the second table; it does not add a third one. When redirecting output, add `--format table`.

- Largest fitting folders expand into named children, direct-files rows and scoped remainder rows. Single-child chains collapse without using additional rows.
- Every measured source contribution appears once. The budget limits additional detail; initial sibling contributions remain visible even if they already exceed it.
- `--sort name` compares path components, keeping descendants together before prefix siblings such as `src-old`. Code ties use the same ordering.
- A muted hint names the largest row when more budget could reveal its child folders. A flat or direct-files row as the largest row produces no hint, even if smaller folders have depth.

The option requires a positive value and supports single-root table output only, including `--subfolder`. It does not change saved JSON, counts, coverage, the Unclaimed source partition or the Language table. Omitting it preserves the existing folder view. See [adaptive folder semantics](../PRODUCT.md#adaptive-folder-detail).

## Terminal safety

Table cells, table notes and application stderr diagnostics flatten control characters from paths and other recorded text before styling. This includes parse-failure and Git submodule notes, partial-results diagnostics and aligned unclaimed-source labels. Intentional list layout remains intact; JSON retains original path identities and evidence.

## Compatibility and upgrading

Configuration and report schema versions remain `1`; this release adds no saved-report fields or counting changes. Saved-report comparisons can still report the producer-version change from 0.2.0 to 0.3.0. Neutral language-level Test/prod ratios and warnings for ineffective presentation options are not included.

Upgrade with `brew update && brew upgrade locmetry`, or install with `brew install mbackschat/tap/locmetry`. Release archives include third-party notices and SHA-256 checksums for macOS arm64 and static Linux x86_64/aarch64 executables. See [installation](../../README.md#install).
