# Compare Counters by What They Measure

Historical snapshot: statements and open findings below describe the pinned research baseline, not current development behavior. S1–S5 subsequently corrected notebook counting/coverage, unified contracts and added `compare` and `explain`; see the [implementation and review record](../plans/archive/measurement-quality-and-net-change.md) for resolutions and the [product contract](../PRODUCT.md) for current guarantees. The original evidence is preserved below.

Research date: 2026-10-15. **Locmetry's useful distinction is its combined classification, policy, workspace, and reporting contract—not basic counting, configuration, multiple inputs, or JSON.** The reviewed counters already provide substantial capabilities in those areas. scc adds unusually broad analytics and presentation; cloc offers extensive selection and diagnostic controls; Tokei supplies embedded-language counting and a Rust API; pygount makes processing states explicit. The comparison also exposed two reproducible Locmetry notebook defects, so a stronger contract must not be mistaken for proven correctness. This report covers the major documented feature families; [configuration and documentation](configuration-and-documentation.md) examines their contracts, and [lessons and open gaps](tool-lessons-and-gaps.md) records the findings for discussion.

## Pin versions before comparing feature families

The baseline is Locmetry 0.1.6 at commit `bece839731d78092e997b5b8b959801324e64b26`, with embedded Tokei 15.0.0. External evidence is pinned to [scc v4.1.0](https://github.com/boyter/scc/tree/v4.1.0), [cloc v2.10](https://github.com/AlDanial/cloc/tree/v2.10), [Tokei v15.0.0](https://github.com/XAMPPRocky/tokei/tree/v15.0.0), [gocloc v0.7.0](https://github.com/hhatto/gocloc/tree/v0.7.0), and [pygount v3.2.0](https://github.com/roskakori/pygount/tree/v3.2.0). Documentation, CLI definitions, serializers, and relevant implementation were inspected; selected upstream tests were read, not executed. No external counter was installed or run. Locmetry's notebook findings were reproduced after building that commit. No performance benchmark, exhaustive language-conformance study, platform matrix, or independent usability study was conducted.

**Supported** means established in the inspected documentation/source, **partial** means a narrower or materially different contract, and **not found** is bounded to the inspected CLI, configuration, processing, and report surfaces. These labels do not rule out wrappers or uninspected branches. Recommendations are inferences from the evidence, not accepted product scope. Saved-report comparison remains a [proposal](../proposals/archive/net-change.md), covered separately in the [net-change research](net-change-tools.md); it is not a shipped Locmetry feature.

## Identical column names conceal different measurements

| Family | Established comparison and implication |
| --- | --- |
| Code, comments, blanks | Tokei/Locmetry and scc use lexical state; cloc uses language filters. Mixed code/comment lines generally count as code, but this does not establish equal totals. pygount treats punctuation-only and some no-op lines as empty and keeps a pure-string distinction. Its summary excludes pure strings from code while SLOCCount/cloc XML include them. **A renderer must not silently redefine Locmetry's metric.** [Tokei syntax](https://github.com/XAMPPRocky/tokei/blob/v15.0.0/src/language/syntax.rs), [scc counter](https://github.com/boyter/scc/blob/v4.1.0/processor/workers.go), [cloc workflow](https://github.com/AlDanial/cloc/blob/v2.10/README.md#how-it-works), [pygount background](https://github.com/roskakori/pygount/blob/v3.2.0/docs/background.md) |
| Docstrings | Locmetry retains Tokei's default docstrings-as-code policy. Tokei can change it through TOML/API; cloc defaults to comments and offers `--docstring-as-code`; scc uses contextual docstring-comment heuristics. Cross-tool totals need explicitly aligned policies. [Locmetry semantics](../measurement.md#counting), [Tokei config](https://github.com/XAMPPRocky/tokei/blob/v15.0.0/src/config.rs), [cloc limitations](https://github.com/AlDanial/cloc/blob/v2.10/README.md#limitations), [scc counter](https://github.com/boyter/scc/blob/v4.1.0/processor/workers.go) |
| Embedded languages | Tokei exposes nested blobs/children; these representations overlap and cannot all be summed. Locmetry normalizes them and preserves host kind/purpose, but currently mishandles notebook parent counts. scc/gocloc have one language field per file; pygount composite names and base-name merging are not additive child counts. cloc explicitly documents embedded-language limitations. [Tokei representation](https://github.com/XAMPPRocky/tokei/blob/v15.0.0/src/language/mod.rs), [Locmetry findings](tool-lessons-and-gaps.md#notebooks-break-two-existing-measurement-guarantees), [scc types](https://github.com/boyter/scc/blob/v4.1.0/processor/structs.go), [gocloc files](https://github.com/hhatto/gocloc/blob/v0.7.0/file.go), [pygount usage](https://github.com/roskakori/pygount/blob/v3.2.0/docs/usage.md), [cloc limitations](https://github.com/AlDanial/cloc/blob/v2.10/README.md#limitations) |
| Recognition and extension | scc/cloc support overrides and discovery beyond extensions; cloc can import/export language filter definitions. Tokei definitions are compiled, though its API accepts an explicit parser. Locmetry mappings select existing parsers only for unrecognized files; they cannot override recognized languages. gocloc uses extension/name/shebang and selected go-enry detection; pygount uses lexers. Language counts are not a parser-quality ranking. [scc detector](https://github.com/boyter/scc/blob/v4.1.0/processor/detector.go), [cloc definitions](https://github.com/AlDanial/cloc/blob/v2.10/cloc#L8831), [Tokei definitions](https://github.com/XAMPPRocky/tokei/blob/v15.0.0/languages.json), [Locmetry mappings](../PRODUCT.md#matching-and-precedence), [gocloc detection](https://github.com/hhatto/gocloc/blob/v0.7.0/language.go), [pygount analysis](https://github.com/roskakori/pygount/blob/v3.2.0/pygount/analysis.py) |
| Unknown files | scc optionally counts unsupported files as plain-text `Unknown`; Locmetry records unrecognized paths/counts and offers mappings. Counting unknown text is not recovery of code/comment semantics. pygount exposes an `unknown` state; Tokei filters failed recognition, optionally logging it. [scc handling](https://github.com/boyter/scc/blob/v4.1.0/processor/file.go), [Locmetry coverage](../PRODUCT.md#reporting-and-coverage), [pygount states](https://github.com/roskakori/pygount/blob/v3.2.0/pygount/analysis.py#L74), [Tokei traversal](https://github.com/XAMPPRocky/tokei/blob/v15.0.0/src/utils/fs.rs) |
| Encoding and binary content | scc skips UTF-8 BOM and tests NULs in an initial byte window; other BOMs warn only in verbose mode, with no transcoding in the inspected path. cloc provides binary overrides and limited Unicode probing; `--file-encoding` concerns output. pygount has BOM/header/fallback/explicit/chardet decoding. Tokei uses BOM-aware decoding; arbitrary-encoding correctness is not established. Locmetry has no content binary filter; an initial existing-binary probe counted a NUL-containing `.rs` as source, with build-identity limits recorded in the linked finding. [scc bytes](https://github.com/boyter/scc/blob/v4.1.0/processor/workers.go), [cloc options](https://github.com/AlDanial/cloc/blob/v2.10/cloc#L1904), [pygount encoding](https://github.com/roskakori/pygount/blob/v3.2.0/docs/usage.md#source-code-encoding), [Tokei parsing](https://github.com/XAMPPRocky/tokei/blob/v15.0.0/src/language/language_type.rs), [Locmetry boundary](tool-lessons-and-gaps.md#evidence-can-improve-scope-without-silently-changing-totals) |
| Generated/minified | scc optionally labels/excludes generated markers from the first 1,000 bytes and minified content using mean bytes per line. pygount records generated filename/header matches, scanning at most the first 15 lines. cloc's `--no-autogen` uses a known-name list plus generated-Go handling. No general content detector was found in Tokei/gocloc/Locmetry; path exclusions remain available. [scc heuristics](https://github.com/boyter/scc/blob/v4.1.0/processor/workers.go), [pygount generated analysis](https://github.com/roskakori/pygount/blob/v3.2.0/pygount/analysis.py#L375), [cloc generated names](https://github.com/AlDanial/cloc/blob/v2.10/cloc#L15296), [Locmetry limits](../measurement.md#limits) |
| Exact duplicates | cloc and pygount remove exact copies by default, with opt-outs; cloc retains the lexical-first path and pygount records the original path. scc's exclusion is opt-in and first-arrival based. gocloc source also deduplicates by default despite confusing flag wording. Tokei/Locmetry do not deduplicate content. Equal bytes can have different ownership, so exclusion changes the measured population. [cloc duplicates](https://github.com/AlDanial/cloc/blob/v2.10/cloc#L1450), [pygount duplicates](https://github.com/roskakori/pygount/blob/v3.2.0/docs/usage.md#counting-duplicates), [scc filter](https://github.com/boyter/scc/blob/v4.1.0/processor/workers.go), [gocloc conditional](https://github.com/hhatto/gocloc/blob/v0.7.0/utils.go#L162), [Locmetry workspace exclusions](../PRODUCT.md#per-member-breakdown) |

## Selection and grouping determine which totals matter

| Family | Established comparison and implication |
| --- | --- |
| Input sources | All reviewed external counters accept multiple local inputs. cloc adds explicit lists/stdin, archives and Git targets; pygount adds remote repositories/revisions. Locmetry deliberately accepts directory roots and separately models workspace members. Archive/VCS input breadth does not establish per-root policy. [cloc inputs](https://github.com/AlDanial/cloc/blob/v2.10/cloc#L1904), [pygount usage](https://github.com/roskakori/pygount/blob/v3.2.0/docs/usage.md), [Locmetry workspace](../PRODUCT.md#workspace-mode) |
| Ignore policy | scc supports `.gitignore`, `.ignore`, `.sccignore`, `.gitmodules` and external ignore files. Tokei uses the ignore walker with `.tokeignore` and parent/global Git context. Locmetry constructs its own backend policy and includes untracked nonignored files. cloc `--vcs=git` instead selects tracked files; gocloc/pygount `.gitignore` readers were not found. These populations are not interchangeable. [scc walker](https://github.com/boyter/scc/blob/v4.1.0/processor/processor.go), [Tokei walker](https://github.com/XAMPPRocky/tokei/blob/v15.0.0/src/utils/fs.rs), [Locmetry selection](../measurement.md#selection-and-paths), [cloc VCS](https://github.com/AlDanial/cloc/blob/v2.10/cloc#L1952), [gocloc walker](https://github.com/hhatto/gocloc/blob/v0.7.0/utils.go), [pygount scanner](https://github.com/roskakori/pygount/blob/v3.2.0/pygount/analysis.py#L574) |
| Hidden paths, links, submodules | scc and Locmetry include hidden files by default; Tokei excludes them; pygount excludes dot paths by default. scc opt-in file-symlink handling and cloc's platform-dependent following differ from Locmetry's no-follow traversal. cloc Git selection excludes submodules unless requested; Locmetry reports source-bearing root `.gitmodules` hints without invoking Git. Platform and explicit-root symlink edges were not tested. [scc handling](https://github.com/boyter/scc/blob/v4.1.0/processor/file.go), [cloc scope](https://github.com/AlDanial/cloc/blob/v2.10/cloc#L2030), [Tokei config](https://github.com/XAMPPRocky/tokei/blob/v15.0.0/src/config.rs), [pygount scanner](https://github.com/roskakori/pygount/blob/v3.2.0/pygount/analysis.py), [Locmetry adapter](../../src/backend.rs) |
| Filters and resource limits | cloc exposes language/extension/path/content filters, line-ignore regexes, archive rules, a default 100 MB traversal cap and filter/diff timeouts. scc offers regex/name filters and optional byte/line caps; its `--no-large` boundary is `>=`, not strictly greater. No configurable size/time caps were found in Locmetry/Tokei/pygount. gocloc's unchecked scanner limit is an error-contract concern. [cloc options](https://github.com/AlDanial/cloc/blob/v2.10/cloc#L2024), [scc limits](https://github.com/boyter/scc/blob/v4.1.0/processor/workers.go), [gocloc parser](https://github.com/hhatto/gocloc/blob/v0.7.0/file.go) |
| Classification and modules | Locmetry has independent kind/purpose/category, first-match provenance and eight descriptor-triggered layout detectors: npm, Gradle, Maven, Cargo, Go, Python, Lake and Swift. They inspect selected filenames, not manifest semantics or actual build membership. scc category buckets are useful test-separation prior art; equivalent orthogonal dimensions/module ownership were not found in the reviewed peers. [Locmetry modules](../../src/modules.rs), [classification contract](../PRODUCT.md#matching-and-precedence), [scc categories](https://github.com/boyter/scc/blob/v4.1.0/processor/processor.go) |

Immediate-parent breakdown is additive; nested Markdown folder rows are recursive and overlap. | Family | Established capability |

Published speed tables do not settle current performance: they use different versions, machines, inputs and defaults. No equal-scope comparison here supports a speed ranking or backend replacement. Tokei's Rust integration remains a concrete architectural fit, while the notebook defects show why an adapter still needs independent expected-count fixtures. The strongest next steps follow from trustworthy measurement and inspectable policy; optional analytics and renderers should follow a demonstrated consumer need rather than the length of a competing flag list.
